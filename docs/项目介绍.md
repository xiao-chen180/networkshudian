# 书香阁网上书店系统 · 项目介绍

> 一个基于 Spring Boot 3 + Vue 3 的前后端分离网上书店示例项目，覆盖「浏览图书 → 加入购物车 → 结算支付 → 订单跟踪 → 会员成长」的完整购物闭环，并配套管理员运营后台。

## 一、项目概述

「书香阁」是一个面向学习与实训场景的网上书店系统。项目采用前后端分离架构：

- **前端**：Vue 3 单页应用，负责页面展示与交互；
- **后端**：Spring Boot 3 REST API，负责业务逻辑、鉴权与数据持久化；
- **数据库**：MySQL，由 JPA 自动建表；
- **鉴权**：JWT（Bearer Token），无状态会话。

系统包含两类角色：

| 角色 | 说明 |
| --- | --- |
| `USER` 普通用户 | 浏览、搜索、收藏、评论、下单、签到、领取优惠券等；注册后默认享受 **95 折** |
| `ADMIN` 管理员 | 管理书籍、订单、用户，查看运营数据；默认 **无折扣** |

## 二、核心功能

### 2.1 前台商城

- **首页门户**：品牌 Hero 区、六大图书分类、精选图书、销量排行、猜你喜欢、随机名言，配合滚动动画与粒子效果。
- **图书浏览**：按分类筛选、关键词检索（书名 / 作者 / ISBN）、分页浏览。
- **图书详情**：封面预览、简介、目录、标签、书评与评分、读者笔记、收藏、加入购物车、立即购买。
- **购物车**：勾选商品、修改数量、删除、清空、实时合计；重复加入同一本书会累加数量。
- **结算下单**：选择或新增收货地址，展示原价、会员折扣、运费（满 99 元免运费，否则 10 元）与应付金额。
- **支付**：支付宝 / 微信两种方式，进入二维码扫码页模拟支付，支付完成后订单变为 `PAID`。
- **订单中心**：查看订单列表与详情、订单状态、删除订单。
- **收货地址**：增删改查、设置默认地址，内置省市区数据。

### 2.2 个人中心与会员体系

- **个人中心**：编辑昵称 / 邮箱 / 手机号、修改密码、资产概览（优惠券、积分、连续签到）、最近订单、地址管理。
- **会员中心**：会员等级、等级折扣、会员权益、消费统计、成长进度与最近订单。
- **每日签到**：连续签到奖励积分；连续 7 / 15 / 30 天额外奖励；连续 7 天解锁前端抽奖转盘。
- **积分中心**：查看当前积分与积分流水（签到获得）。
- **优惠券**：领取可用优惠券、查看我的券、按门槛/类型试算优惠金额。
- **社区互动**：发表书评与 1–5 星评分、收藏图书、撰写读书笔记、给笔记点赞。
- **消息中心**：查看系统消息、未读数、标记已读 / 全部已读。
- **排行榜**：销量榜、评分榜、新书榜。
- **其他体验**：深色模式、图片懒加载、骨架屏、加入购物车动画、页面过渡动画。

### 2.3 管理员后台

- **数据概览**：用户数、管理员数、订单总数与各状态分布、总营收、图书数量、低库存预警、最近订单。
- **书籍管理**：上架、编辑、删除图书；按书名 / 作者 / ISBN 搜索；按分类筛选；**批量调价**（全库或指定分类，固定金额或百分比）。
- **订单管理**：按状态筛选；发货（`PAID → SHIPPED`）、完成（`SHIPPED → COMPLETED`）、取消（恢复库存）。
- **用户管理**：查看用户信息、订单数、折扣；设置 / 取消管理员。

## 六、快速开始

### 6.1 环境要求

| 依赖 | 建议版本 |
| --- | --- |
| JDK | 17+ |
| Maven | 3.9+（或直接使用仓库自带 `mvnw`） |
| MySQL | 8.x |
| Node.js | 18+（建议 20 LTS） |
| npm | 9+ |

### 6.2 初始化数据库

```sql
CREATE DATABASE IF NOT EXISTS shixun
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

数据表由 Hibernate 在首次启动时自动创建（`spring.jpa.hibernate.ddl-auto: update`），无需手动建表。

### 6.3 启动后端

数据库连接默认见 [`application.yml`](../springboot/src/main/resources/application.yml)：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/shixun?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true&characterEncoding=UTF-8
    username: root
    password: 123456
```

如需修改账号密码，直接编辑该文件（或改为环境变量，见开发文档「构建与部署」）。

```bash
cd demo/springboot
../mvnw spring-boot:run
# Windows CMD: ..\mvnw.cmd spring-boot:run
```

启动成功后 API 地址为 `http://localhost:8080`。首次启动会自动写入 6 个分类和百余本示例图书。

### 6.4 启动前端

```bash
cd demo/vue
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。

> 前端 API 地址默认是 `http://localhost:8080`，可通过环境变量 `VITE_API_BASE_URL` 覆盖（见 [`vue/src/api/index.js`](../vue/src/api/index.js)）。

### 6.5 创建管理员账号

系统**不会自动创建管理员**。推荐直接在数据库中把已注册用户的角色改为管理员：

```sql
UPDATE users SET role = 'ADMIN', discount = 1.00 WHERE account = '你的账号';
```

如需通过注册接口创建管理员，可先在启动后端时配置环境变量 `BOOKSTORE_ADMIN_SECRET`，再在注册请求中携带相同的 `adminSecret`。未配置时该能力默认关闭：

```bash
# 启动后端前设置（Windows PowerShell 示例）
$env:BOOKSTORE_ADMIN_SECRET="请换成足够长的随机字符串"

curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"account":"admin","username":"管理员","password":"123456","email":"admin@example.com","phone":"","adminSecret":"与上面相同的值"}'
```

随后在 `http://localhost:5173/admin-login` 使用该账号登录。注册页本身不提供管理员密钥输入框。

## 七、初始数据说明

- **分类**：文学小说、科技计算机、历史传记、经济管理、教育学习、哲学宗教（仅在分类表为空时初始化）。
- **图书**：启动时按 ISBN 写入 / 更新百余本示例图书，包含简介、目录、库存等；重复 ISBN 以更新已有记录的方式处理。
- **用户**：无默认账号。普通用户注册即获得 `USER` 角色与 **0.95 折扣**；管理员 `ADMIN` 折扣为 1.0。
- **余额**：用户首次访问余额接口时自动创建账户，初始余额 **100.00** 元（余额支付流程已实现，但当前前端支付页未使用；为避免任意加款，未提供公开充值接口）。
- **优惠券 / Banner / 名言**：没有内置种子数据，需通过接口或数据库手工添加。

## 八、说明与限制

本项目定位为学习 / 实训示例，部分实现为演示性质：

1. **支付为模拟流程**：二维码为静态图片，点击「已完成支付」直接把订单状态改为 `PAID`，未接入真实支付网关。
2. **部分页面数据为静态**：会员中心（VIP）的成长值、累计消费、加入时间等为前端写死；签到抽奖结果不落库。
3. **接口鉴权手工实现**：公开读接口放行，管理后台与图书 / 分类 / 标签的写接口已要求管理员角色；其余用户接口仍由各控制器解析 JWT 自行判断登录态。
4. **优惠券未参与结算**：结算页没有选择优惠券的入口，优惠券接口仅支持领取与试算。
5. **配置中的明文密钥**：`application.yml` 包含本地数据库密码与 JWT 密钥，仅适合本地开发；部署前务必替换。
