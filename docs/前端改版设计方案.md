# 书香阁 · 前端改版设计方案（深夜书房 / Nocturne）

> 版本：v2.0（2026-11-26）
> 视觉方向：**深夜书房（Nocturne Editorial）**
> 范围：前台 19 个页面 + 管理后台 2 个页面
> 设备：桌面优先（1440 / 1280 / 1024），向下适配 768 / 375
> 技术路线：保留 Vue 3 + Element Plus，自建 token 与业务组件，Element Plus 只做行为层

本文件替代 v1.0（文艺杂志风）方案。v1 的「纸感 + 墨绿 + 宋体 + 大留白」方向已废弃。

---

## 1. 视觉方向与原则

**核心意象**：一间深夜还亮着灯的书店。暗底、暖光、细线、衬线标题。

| 原则 | 说明 |
|---|---|
| 靠明度分层，不靠阴影 | 页面 `#0C0D10` → 卡片 `#171A1F` → 输入 `#1E222A`，用三层底色区分层级 |
| 金色是强调，不是装饰 | 只用于价格、主按钮、选中态、数据强调、细线 |
| 衬线标题 + 无衬线正文 | 标题 Noto Serif SC 400 字重、字距 0.12–0.18em；正文 Noto Sans SC |
| 无圆角、无渐变装饰 | 圆角 ≤ 2px，去掉所有渐变球、粒子、云纹，保留极少量径向暖光 |
| 封面 | 使用本地真实图书封面（`vue/public/covers`），加载失败或缺失时回退程序化书封（色块 + 大首字暗纹 + 金色细框 + 书名/作者） |

## 2. 设计 Token

### 2.1 色彩

| 角色 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#0C0D10` | 页面底色 |
| `--color-surface` | `#171A1F` | 卡片、面板 |
| `--color-surface-2` | `#1E222A` | 输入框、次级面板 |
| `--color-surface-3` | `#242932` | 进度条底、骨架屏 |
| `--color-ink` | `#F3EFE7` | 主文字 |
| `--color-ink-soft` | `#BCB6A9` | 正文 |
| `--color-ink-muted` | `#8B8578` | 辅助文字 |
| `--color-ink-faint` | `#615C53` | 弱提示、占位符 |
| `--color-line` | `rgba(255,255,255,.10)` | 分隔线 |
| `--color-line-strong` | `rgba(255,255,255,.18)` | 强调分隔线 |
| `--color-gold` | `#D3AE6A` | 品牌强调色 |
| `--color-gold-line` | `rgba(211,174,106,.38)` | 金色描边 |
| 状态色 | 鼠尾草 `#86A297` / 砖红 `#C9745C` / 成功 `#7D9B82` / 提示 `#7A97A6` | 订单状态、警告 |

### 2.2 字体与字号

| 角色 | 字体 / 规格 |
|---|---|
| 展示标题 | Noto Serif SC 400 · 62px / 1.38 · 字距 0.04em |
| 页面标题 H1 | Noto Serif SC 400 · 42px · 字距 0.12em |
| 区块标题 H2 | Noto Serif SC 400 · 26–28px · 字距 0.14em |
| 正文 | Noto Sans SC · 14px / 2.0 |
| 小字 | 12px；辅助 10–11px |
| 数字 | `font-variant-numeric: tabular-nums`，价格用衬线 |

### 2.3 间距 / 布局 / 动效

- 间距刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 120
- 容器 1160px，栏距 24px，区块间距 72–82px
- 圆角：0 / 2px；阴影只用于弹层（`0 16px 48px rgba(0,0,0,.55)`）
- 动效：120 / 220 / 320ms，`cubic-bezier(.2,.7,.2,1)`；只保留页面淡入、骨架屏、必要状态反馈

### 2.4 Element Plus 映射

`theme.css` 中已完成全量变量覆盖：主色、背景、文字、边框、填充、表格、弹窗、输入框、按钮、标签全部映射到上述语义色，弹窗与表单不再出现白底。

## 5. 交互与状态规范

- **加载**：列表页用骨架卡（`BookCard loading`），详情页用骨架块；
- **空态**：统一 `EmptyState`（图标 + 标题 + 说明 + 一个主要动作），文案说明下一步做什么；
- **错误**：接口失败不阻断页面，降级为空态或 0 值；表单错误用 `ElMessage`；
- **禁用**：售罄商品按钮置灰并显示「暂时缺货」；未登录点击加购跳登录；
- **确认**：删除图书、取消订单等破坏性操作使用 `ElMessageBox` 二次确认。

## 6. 无障碍与响应式

- 所有可点击元素使用 `button` / `a`，封面链接带 `aria-label`（书名 + 作者 + 价格）；
- 焦点可见：`:focus-visible` 金色描边；
- 对比度：主文字 `#F3EFE7` 对 `#0C0D10` ≈ 15:1，辅助文字 ≥ 4.5:1；
- 断点：1024（侧栏折叠为顶部）、768（单列，隐藏部分元信息）、375（移动单列）；
- 尊重 `prefers-reduced-motion`，关闭动画。

## 7. 与旧版的差异（验收要点）

| 项 | v1（杂志风） | v2（深夜书房） |
|---|---|---|
| 底色 | 米黄纸感 | 近黑分层 |
| 主色 | 墨绿 + 朱砂 | 暖金 |
| 封面 | 外链 `picsum.photos` | 程序化绘制，离线可用 |
| 深色模式 | 变量只覆盖少量 | 全站单一深色系统，无需切换 |
| 后台 | 深色侧栏 + 亮色内容混排 | 与前台同一套深色系统 |
| 优惠券 | 仅可领取 | 结算真实抵扣 + 订单核销 + 取消退回 |
