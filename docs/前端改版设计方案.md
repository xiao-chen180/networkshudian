## 1. 用户与目标

### 1.1 目标用户

| 用户 | 场景 | 关键诉求 |
| --- | --- | --- |
| 普通读者 | 找书、看简介与目录、比价、下单 | 快速找到想读的书；内容可信；购买路径顺 |
| 注册会员 | 收藏、写笔记、领券、签到、看订单 | 有归属感；权益真实可用；进度可感知 |
| 管理员 | 上架、调价、发货、处理订单 | 信息密度高、操作快、状态清晰 |

### 1.2 产品目标

1. **视觉上像一本可以逛的书店**，而不是一个套了模板的后台系统；
2. **购买主链路 3 分钟内可完成**，每一步都有明确反馈；
3. **会员、优惠券、积分、签到等运营功能真实闭环**，不再是假数据；
4. **全站一致**：同一套字体、间距、组件、状态与动效语言；
5. **可维护**：页面组件化，单文件不超过 500 行，样式全部走 token。

### 1.3 使用场景与约束

- 主要在桌面浏览器购书，移动端用于浏览与轻量操作；
- 中文内容为主，需考虑中文标点、行长与字重；
- 现有技术栈与后端接口保留，改版以「前端结构 + 样式 + 少量接口补齐」为主；
- Element Plus 继续负责表单、弹窗、消息提示，但不作为视觉主体。

## 2. 现状诊断

### 2.1 视觉问题

| 问题 | 表现 |
| --- | --- |
| 风格不统一 | 首页有粒子、云纹、卷轴等强装饰；列表页偏工具化；后台又是另一套深色侧栏 |
| 信息层级弱 | 标题、正文、辅助文字字号接近，页面缺少「编辑重心」 |
| 卡片过重 | 阴影、圆角、渐变叠加，视觉噪音大 |
| 图片不可控 | 全站封面依赖 `picsum.photos` 外链，离线裂图、风格随机 |
| 深色模式不完整 | 只覆盖少量变量，大量页面写死白色/深灰 |
| 移动端缺失 | 无汉堡菜单、无断点、登录页固定 450px 宽 |
| 动效廉价 | 弹跳、旋转、长时间入场动画过多，缺少克制的内容动效 |

### 2.2 结构问题

- 24 个路由平铺，导航只露出 5 个入口，优惠券、积分、会员、签到等入口分散在个人中心；
- 页面组件过大：`Admin.vue` 2080 行、`BookDetail.vue` 1546 行、`Home.vue` 1026 行；
- 公共组件复用不足，`Header` / `Navbar` 概念重复（已清理）；
- 无状态管理，登录态、购物车数量、主题在页面间重复读取 `localStorage`；
- 无统一 loading / empty / error 三态。

### 2.3 功能缺口

- 优惠券可领取、可试算，但结算时无法使用；
- 会员等级、成长值、累计消费为前端写死；
- 签到抽奖不落库、可无限抽；
- 消息中心无自动消息；
- 搜索无排序、无价格/评分筛选；
- 订单金额不含运费，支付为模拟；
- 管理后台趋势数字写死，列表无分页。

> 本方案同时给出视觉与功能两部分的改造路线，功能部分见第 10 节。

## 3. 设计方向

### 3.1 核心概念：**「一册正在被翻阅的杂志」**

把书店当成一本刊物来设计：

- **刊头**：站点导航像杂志的 masthead，保留品牌名与期号；
- **专题**：首页以「本期主题 / 编辑精选」组织内容，而不是商品瀑布流；
- **目录**：分类、排行榜用编号与细线排版，像目录页；
- **正文**：图书详情以阅读页的排版呈现简介、目录与书评；
- **留白**：大量呼吸感，让封面与文字成为主角；
- **克制的点缀**：朱砂红只用于价格、强调与关键按钮；金色只用于细线与小面积装饰。

### 3.2 设计原则

1. **文字优先**：标题有字号与字重差，正文行长控制在 32–38 个汉字；
2. **一屏一个重点**：每个区块只有一个主信息，不做「什么都想突出」；
3. **细线代替阴影**：用 1px 边框与纸色分层，减少投影；
4. **动效服务于阅读**：入场只做轻淡入与位移，时长 200–320ms；
5. **编辑感来自秩序**：统一栅格、编号、对齐与留白，而不是贴装饰；
6. **可访问优先**：对比度、焦点、键盘与 reduced-motion 全部纳入验收。

### 3.3 视觉关键词

`纸感` · `墨色` · `宋体标题` · `细线` · `编号` · `大留白` · `朱砂点缀` · `克制动效`

| Token | 值 |
| --- | --- |
| `--space-1` … `--space-12` | 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 120 |
| `--container` | 1280px |
| `--container-narrow` | 960px |

| `--grid-columns` | 12 |

断点：

| 名称 | 宽度 | 布局变化 |
| --- | --- | --- |
| `desktop-xl` | ≥ 1440 | 容器 1280，栅格 12 列 |
| `desktop` | 1024–1439 | 容器自适应，栅格 12 列 |
| `tablet` | 768–1023 | 栅格 8 列，侧栏折叠 |
| `mobile` | < 768 | 单列，导航抽屉，底部操作条 |

### 4.5 圆角与描边

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-none` | 0 | 图片、表格、编辑式卡片 |
| `--radius-sm` | 2px | 标签、输入框 |
| `--radius-md` | 4px | 按钮、卡片 |
| `--radius-pill` | 999px | 仅用于状态标签，不用于大按钮 |
| `--border-hairline` | 1px solid `--color-rule` | 卡片、分隔 |

> 方向选择：**刻意少用圆角与阴影**，靠细线、纸色与留白分层。

### 4.6 阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--shadow-none` | none | 默认卡片 |
| `--shadow-hover` | `0 8px 24px rgba(28,27,25,.08)` | 卡片悬停 |
| `--shadow-popover` | `0 12px 32px rgba(28,27,25,.14)` | 下拉、弹层 |

### 4.7 动效

| Token | 值 |
| --- | --- |
| `--duration-fast` | 150ms |
| `--duration-normal` | 240ms |
| `--duration-slow` | 320ms |
| `--ease-standard` | `cubic-bezier(.2,.7,.2,1)` |
| 入场 | opacity 0→1 + translateY 8px |
| 悬停 | 位移 2px + 图片缩放 1.02 |
| 页面切换 | 淡入 200ms |

规则：

- 禁止弹跳、旋转、长时间循环动画；
- `prefers-reduced-motion: reduce` 时关闭位移与缩放，仅保留透明度；
- 同一屏同时动画元素不超过 8 个。

### 4.8 层级

| Token | 值 |
| --- | --- |
| `--z-nav` | 30 |
| `--z-dropdown` | 40 |
| `--z-sticky` | 50 |
| `--z-modal` | 60 |
| `--z-toast` | 70 |
| `--z-skip-link` | 80 |

## 6. 全局布局

### 6.1 页头（Masthead）

- 高度：桌面 72px，滚动后 56px 并加 1px 底线；
- 结构：品牌 / 导航 / 工具区三栏；
- 移动端：品牌 + 汉堡 + 购物袋；菜单从左侧抽屉展开，含二级入口；
- 键盘：`Tab` 顺序 = 品牌 → 主导航 → 搜索 → 购物袋 → 消息 → 用户；
- 页头不吸顶遮挡内容，滚动后仅保留导航条。

### 6.2 页脚

四栏：品牌与一句话介绍 / 购物指南 / 会员服务 / 关于我们；底部一条细线 + 版权与备案占位。移动端纵向堆叠。

### 6.3 管理后台

- 独立的「工作台」皮肤：墨绿侧栏 + 纸色内容区，但不使用大标题衬线装饰；
- 左侧分组：概览 / 书籍 / 订单 / 用户 / 优惠券 / 内容；
- 顶栏：面包屑 + 搜索 + 管理员菜单；
- 表格、筛选、批量操作密度高于前台，组件复用同一套 token。

### 6.4 页面骨架

│ Main（12 栅格）                                             │
│   ┌──────────────┬───────────────────────────────┐          │

│   └──────────────┴───────────────────────────────┘          │
├────────────────────────────────────────────────────────────┤

## 7. 页面级改造规格

> 以下按「页面 → 目标 → 布局 → 关键组件 → 状态 → 移动端」描述，24 个页面全部覆盖。

### 7.1 首页 `/`（Home）

**目标**：3 秒内传达「这是一家认真选书的书店」，并给出 3 条下一步路径（逛分类 / 看榜单 / 看专题）。

**布局**：

```text
┌──────────────────────────────────────────────────────────────┐
│ VOL.01 / 2026 秋                              本期主题：重读  │
├───────────────────────────┬──────────────────────────────────┤
│ 大标题（宋体 2 行）         │  本期封面书（3:4 大图）           │
│ 一句编辑导语                │  书名 / 作者 / 一句推荐语          │
│ [ 开始选书 ] [ 看本期书单 ] │  [ 加入购物袋 ]                   │
├───────────────────────────┴──────────────────────────────────┤
│ 本期书单  ① ② ③ ④（横向 4 本，编号 + 细线）                    │
├──────────────────────────────────────────────────────────────┤
│ 典籍分类（编号索引，6 项两列）  │  本周榜单（销量/评分 tab）       │
├──────────────────────────────────────────────────────────────┤
│ 编辑荐语（大段引用 + 竖排小标签）                               │
├──────────────────────────────────────────────────────────────┤
│ 猜你喜欢（4 本）                                               │
└──────────────────────────────────────────────────────────────┘
```

**关键组件**：`Masthead`、`IssueLabel`、`FeatureBook`、`CollectionRow`、`CategoryIndex`、`RankingList`、`QuoteBand`、`BookCard`。

**状态**：

- 加载：骨架（标题条 + 封面块 + 4 个卡片）；
- 空：分类/榜单为空时显示编辑式占位文案，不展示虚构书籍；
- 错误：区块级错误提示 + 重试，不整页崩溃；
- 登录/未登录：未登录时「加入购物袋」引导登录并保留当前页。

**移动端**：Hero 改为上下结构；书单横向滑动（带进度点）；分类两列；榜单 5 条 + 「查看全部」。

**数据需求**：分类、精选/推荐、销量榜、评分榜、名言/Banner（可选）。现有接口基本满足。

### 7.2 图书列表 `/books`（Books）

**目标**：高效筛选与比较，同时保持杂志感。

**布局**：页头（标题 + 共 N 本 + 排序）→ 左侧筛选栏（分类、价格区间、评分、标签）→ 右侧 4 列网格（首项可跨 2 列作为编辑推荐）。

**关键组件**：`PageHeader`、`FilterRail`（可折叠）、`SortSelect`、`BookCard`（grid）、`Pagination`、`EmptyState`。

**状态**：

- 加载：12 个卡片骨架；
- 空：插画式空状态 + 「清除筛选」；
- 错误：保留筛选栏，内容区错误 + 重试；
- 部分数据：封面缺失用本地占位；分类缺失显示「未分类」。

**移动端**：筛选改为底部抽屉；2 列网格；排序吸顶。

**数据需求**：现有分页接口 + 排序参数（新增 `sort=sales|rating|new|price_asc|price_desc`）、价格/评分筛选（可先前端筛选当前页，P1 后后端支持）。

### 7.3 图书详情 `/books/:id`（BookDetail）

**目标**：让读者在 30 秒内决定「读不读、买不买」。

**布局**：左侧 5 栏（封面 + 小图/预览）、右侧 7 栏（书名、作者、出版社、评分、价格、数量、加购/立即购买、收藏）；下方通栏 Tabs（简介 / 目录 / 书评 / 笔记 / 相关推荐）。

**状态**：

- 加载：封面骨架 + 标题条 + 按钮禁用；
- 404：书籍下架页面 + 返回列表；

### 7.4 购物袋 `/cart`（Cart）

**目标**：清楚展示「买了什么、多少钱、下一步做什么」。

### 7.5 结算 `/checkout`（Checkout）

## 8. 核心流程与状态

### 8.1 购书主流程

```text
首页/列表 ──▶ 详情 ──▶ 加购 ──▶ 购物袋 ──▶ 结算 ──▶ 支付 ──▶ 扫码 ──▶ 成功/订单
   │            │         │           │          │
   │            │         │           │          └─ 失败：重试 / 换方式
   │            │         │           └─ 无地址：新增地址抽屉
   │            │         └─ 未登录：登录后回跳，保留加购
   │            └─ 无库存：缺货提示 + 到货提醒
   └─ 空数据/错误：区块级重试
```

**每一步的状态要求**：

| 步骤 | Loading | Empty | Error | 成功反馈 |
| --- | --- | --- | --- | --- |
| 列表 | 骨架 | 空状态 + 清除筛选 | 保留筛选 + 重试 | 卡片出现 |
| 详情 | 骨架 + 禁用按钮 | — | 404 / 下架页 | — |
| 加购 | 按钮 loading | 未登录引导 | toast + 重试 | 购物袋数量 +1 + 轻提示 |
| 购物袋 | 行骨架 | 空袋引导 | 行内错误 | 数量/金额即时更新 |
| 结算 | 地址/券骨架 | 无地址卡片 | 字段错误 + 提交失败 | 跳转支付 |
| 支付 | 按钮 loading | — | 失败提示 + 重试 | 跳扫码/成功 |
| 扫码 | 二维码 loading | — | 超时/失败 | 成功页 |

### 8.2 会员与积分流程

```text
签到 ──▶ 获得积分 ──▶ 积分流水
  │
  └─ 连续 7 天 ──▶ 抽奖（后端落库）──▶ 奖励入账
消费 ──▶ 成长值/累计消费 ──▶ 会员等级 ──▶ 折扣生效
```

状态：今日已签到、断签重置、抽奖次数用尽、等级升级提示。

### 8.3 订单状态

```text
PENDING ──支付──▶ PAID ──发货──▶ SHIPPED ──确认──▶ COMPLETED
   │                 │               │
   └─ 取消 ──▶ CANCELLED ◀── 取消 ───┘
```

前端展示规则：

- 待付款：倒计时 + 去支付 + 取消；
- 已付款：等待发货；
- 已发货：确认收货；
- 已完成：查看详情 / 再次购买；
- 已取消：删除订单（仅待付款/已取消）。

### 8.4 关键边界

| 场景 | 处理 |
| --- | --- |
| 登录过期 | 保存当前路径，登录后回跳；toast 说明 |
| 库存变化 | 下单失败明确提示具体书名；返回购物袋处理 |
| 价格变化 | 结算以服务端返回为准，金额变化时提示 |
| 重复提交 | 所有提交按钮 loading + 防抖 + 后端幂等 |
| 网络失败 | 区块级错误，不白屏；重试按钮 |
| 刷新支付页 | 已有 `orderId` 不重复建单 |
| 优惠券失效 | 结算时重新校验，失效则移除并提示 |
| 移动端返回 | 保留筛选/分页状态（query 同步） |

### 9.2 组件规格示例：`BookCard`

**Purpose**：在列表、首页、收藏、推荐中统一呈现一本书，并提供进入详情与快捷加购。

**Variants**：`grid`（默认）、`list`（横排，购物袋/订单用）、`ranking`（带名次）。

**Props**（Vue `defineProps`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `book` | `Book` | 书籍数据（id/name/author/price/cover/rating/sales） |
| `variant` | `'grid' \| 'list' \| 'ranking'` | 形态 |
| `rank` | `number?` | ranking 名次 |
| `showAction` | `boolean` | 是否显示快捷加购 |
| `loading` | `boolean` | 骨架态 |

**States**：

| 状态 | 表现 | 行为 |
| --- | --- | --- |
| Default | 封面 3:4、书名两行截断、作者、价格 | 点击进详情 |
| Hover | 上移 2px、封面 1.02、显示「查看」 | 不遮挡信息 |
| Focus | 2px 墨绿焦点环 | 键盘可达 |
| Loading | 封面与文字骨架 | 不响应点击 |
| Missing cover | 本地占位图 + 书名首字 | 不请求外链 |
| Sold out | 封面蒙层「缺货」 | 加购禁用 |

**Responsive**：桌面 4 列（≥1280）/ 3 列（1024）/ 2 列（768）/ 2 列（375）；list 形态全宽。

**Accessibility**：整个卡片是一个链接（`<router-link>`），`aria-label="《书名》，作者，¥价格"`；快捷加购按钮独立可聚焦，`aria-label="将《书名》加入购物袋"`；封面 `alt` 使用书名。

**Motion**：hover 240ms `--ease-standard`；reduced-motion 时只改边框色。

### 9.3 组件规格示例：`EmptyState`

- Props：`icon`、`title`、`description`、`actionText`、`actionTo`；
- 状态：默认 / compact（表格内）；
- 可访问性：`role="status"`，文案即说明，不依赖图标；
- 移动端：垂直居中，最大宽度 320px。

> 其余组件按同一格式在实现前补充到 `docs/组件规格.md`，至少包含 props、状态、响应式、可访问性与验收标准。

| 签到与抽奖 | 抽奖纯前端 | 抽奖接口、次数与奖品落库；每日限制 | CheckInService、新 LotteryService |

| 消息触发 | 无消息 | 订单状态变化、优惠券到期等节点发送站内信 | MessageService 调用点 |
| 图片 | 外链随机图 | 本地占位 + 后台上传/URL 字段；统一 `BookCover` | 前端组件、管理后台 |

### P1 · 体验与运营增强

- 书单/专题（Collections）：编辑精选集合，支持排序与封面；

## 12. 可访问性、性能与内容规范

### 12.1 可访问性（WCAG 2.1 AA）

- 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1；纸色与墨色组合已满足；
- 所有交互元素有可见焦点环（2px `--color-moss`，偏移 2px）；
- 图片 `alt`：封面用「《书名》封面」；装饰图 `alt=""`；
- 表单使用显式 `<label>`，错误信息与字段 `aria-describedby` 关联；
- 弹窗焦点陷阱、Esc 关闭、关闭后焦点返回触发元素；
- 购物袋数量变化、加购成功通过 `aria-live="polite"` 播报；
- 支持 `prefers-reduced-motion`；
- 提供「跳到主要内容」跳过链接。

### 12.2 性能

- 路由级懒加载已存在，保持；
- 组件库按需引入（Element Plus 自动导入），目标首屏 JS < 500KB gzip；
- 封面统一使用 `loading="lazy"`、固定宽高比、`srcset`（如有多尺寸）；
- 字体：系统字体优先；自定义字体仅 2 个字重并子集化；
- 骨架屏代替全屏 loading；
- 列表分页/虚拟滚动（数据量大时）。

### 12.3 内容与文案

- 标题 6–12 字，避免营销腔；
- 区块导语 1 句，20–40 字；
- 书评/简介正文行长 32–38 字，段间距 1em；
- 空状态文案给下一步动作，不只说「暂无数据」；
- 金额、日期、订单号使用等宽数字对齐；
- 中文标点全角，中英文之间加空格。

## 13. 风险与依赖

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 全站 24 页一次性重构 | 周期长、回归面大 | 按 Phase 1/2 分批；先搭基座再改页面 |
| 后端功能未闭环 | 视觉改版后仍显「假」 | P0 功能与视觉并行；先做优惠券/会员/订单 |
| Element Plus 默认样式冲突 | 视觉不统一 | 统一变量覆盖；业务组件自建 |
| 字体体积 | 首屏变慢 | 系统字体优先，按需子集化 |
| 移动端工作量 | 容易拖期 | 先做 375 关键页，逐步补齐 |
| 现有超大组件 | 改动风险 | 改版时同步拆分，避免在 2000 行文件里打补丁 |
| 未提交的后端 DTO 改造 | 可能与新前端字段不一致 | 改版前先确定 API 契约，再继续后端改造 |
